# D-017: New decision IDs start at D-016. Section 5 ordering is cosmetic

- **Status:** Proposed
- **Date:** 2026-11-03
- **Raised by:** PM, docs setup
- **Context:** Brief 11.1 shows `docs/decisions/` holding "D-015-….md for new decisions", but D-015 is already used in Section 5. Section 5 also lists D-015 before D-014.
- **Decision:** Read the 11.1 example as a filename pattern. New decisions start at **D-016**. The D-014/D-015 order is cosmetic, so no action is taken and the brief isn't edited.
- **Why:** Reusing D-015 would give two different decisions the same ID. Reordering would mean editing the read-only brief.
- **Consequences:** None for the product.
